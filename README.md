# Iron & Grace

A Scripture-centered weekly men's Bible study hub: daily ESV readings, reflection prompts, brotherhood check-ins, and meeting planning.

## Current version

The first prototype contains Week 1, **Strength Under Christ**, a 12-week topic outline, a one-hour gathering guide, local daily-reading progress, device-local check-ins, shareable group-chat prompts, availability sharing, and a Google Calendar event link.

- ESV passages are referenced and open through ESV.org; the ESV text is not bundled.
- Check-ins and reading progress are stored in the visitor's browser only.
- Group messages and meeting availability are shared using the visitor's messaging/share app.
- Live shared chat, server-saved member profiles, and automatically tallied availability are not connected yet.
